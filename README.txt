HM OFFICIAL — starter portfolio website

FILES
- index.html: page content
- style.css: layout and design
- script.js: mobile menu and footer year
- profile.jpg: add your own portrait photo using this exact filename

PREVIEW ON WINDOWS
1. Extract this ZIP folder.
2. Double-click index.html to preview in your browser.

PUBLISH ON VERCEL (GitHub method)
1. Create/sign in to GitHub and make a new repository named hm-official.
2. Upload index.html, style.css, script.js and your profile.jpg (optional).
3. Open https://vercel.com and sign in.
4. Choose Add New > Project, import the hm-official GitHub repository.
5. Keep Framework Preset as Other. Leave Build Command and Output Directory empty.
6. Press Deploy. Vercel will give you a live website address.

EDITING
- Change the intro and project text in index.html.
- Replace the Facebook link with your real public profile/page URL.
- Put your own portrait in this folder and name it profile.jpg.
- Never put passwords, private account details or secret keys in website files.
